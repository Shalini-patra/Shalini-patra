### 🏥 [Healthcare Analytics & Predictive Bed Management](http://github.com/Shalini-patra/Healthcare_Project/blob/main/README.md)

Healthcare analytics platform built using **Python, SQL, Power BI, Grafana and Scikit-learn**.

* Analyzed **250K+ synthetic patient records**
* Built a Gradient Boosting model for **Length of Stay prediction**
* Identified **₹30.23M** in discharge-delay opportunity costs
* Analyzed admission bottlenecks, staffing requirements and profitability
* Built dashboards for patient flow, occupancy and operational KPIs

**Focus:** Healthcare Analytics • Predictive Analytics • Operational Analytics • ML
